**BG Chrome Extension**

A lightweight Chrome extension that surfaces verses from the Bhagavad Gita. The project includes a React-based UI, a background script, and the extension manifest so the extension can be built and loaded into Chrome as an unpacked extension.

**Key Features**
- Display Bhagavad Gita verses with a simple, readable UI.
- Offline-ready data bundled in `src/data/bhagavad-gita.json`.
- Small background script to support extension behavior.

**Repository Structure**
- `src/` — React source code and components (see [src/components/VerseDisplay.js](src/components/VerseDisplay.js#L1)).
- `public/` — static files used during development.
- `build/` — production-ready extension assets generated by `npm run build`.
- `manifest.json` — extension manifest found in `public/` and copied to `build/` during a production build.

Getting started
-----------------

Prerequisites: Node.js (16+) and npm.

1. Install dependencies

```bash
npm install
```

2. Development (view the React app)

```bash
npm start
```

This launches the React development server at http://localhost:3000. Note: the development server is useful for UI work; to test the extension in Chrome use a production build as described below.

3. Build the extension for Chrome

```bash
npm run build
```

This outputs a production-ready extension into the `build/` directory. To load the extension in Chrome:

- Open `chrome://extensions`
- Enable "Developer mode"
- Click "Load unpacked" and select the `build/` folder

Usage
-----

After installing the unpacked extension, click the extension icon in the browser toolbar to open the UI and browse verses.

Contributing
------------

Contributions are welcome. Please open an issue or submit a pull request.

If you plan to work on the extension UI, run `npm start` and develop against the React app. For changes that affect extension behavior (background scripts, manifest), make sure to run `npm run build` and test by loading the `build/` folder into Chrome.
